# Night in the Woods · Xbox PC 中文适配补丁

非官方的 **Xbox / 微软商店 PC 版剧情与菜单中文补丁**，附带有线 DualSense Edge 后备映射和 Enter 确认键。采用资源差分安装，提供原件校验、备份、模式切换与恢复。

对白译文来自[识渡汉化组公开工程](https://github.com/Know-Team/NITW_zh-Hans-CN_l10n)。本仓库负责 Xbox 版适配与工具，完整署名见 [CREDITS.md](CREDITS.md)。

## 下载与安装

到本仓库 **Releases** 下载附件：

`NITW-Xbox-CN-v0.1.0-beta.1-win-x64.zip`

GitHub 自动生成的 `Source code.zip` 是开发源码；可直接安装的差分数据放在上述 Release 附件中。

1. 正常退出游戏。
2. 右键安装包，选择 **“全部解压”**，进入解压后的普通文件夹 `NITW-Xbox-CN`。
3. 双击 `2-Install-Chinese.cmd`，安装汉化与输入修复。安装器会尝试寻找常规 Xbox 安装目录，找不到或找到多个时会让你填写游戏的 `Content` 路径。
4. 完成后自行从 Xbox 启动游戏，保持原来的英文语言选项。

请保持 CMD、`Install.ps1` 和 `PatchData.zip` 在同一文件夹；内部的 `PatchData.zip` 保持压缩状态。`Install.ps1` 是由 CMD 调用的 PowerShell 脚本，Windows 显示为 PowerShell 文件属于正常情况。

| 入口 | 用途 |
| --- | --- |
| `1-Input-Fix.cmd` | 仅安装输入修复 |
| `2-Install-Chinese.cmd` | 汉化与输入修复一起安装 |
| `3-Restore-Original.cmd` | 恢复安装前的原始资源 |

详细步骤、手动指定目录和故障处理见 [安装说明](docs/INSTALL.md)。

## 内容

- 127 个剧情文本资源：替换 23,969 条含中文的对白与选项。
- 152 处菜单文字；2,764 个中文及扩展字形；四个菜单字体资源。
- 以 Xbox 原件的行号匹配译文，保留原节点、跳转目标、条件与流程命令；修正三处上游选项目标与此构建大小写不一致的问题。
- 保留原默认按键，额外增加 Enter 交互/确认。
- 添加针对有线 DualSense Edge 的未知控制器后备映射，并允许单玩家同时分配两个手柄设备。

其余 1,024 条匹配行主要是标点、表情、空文本、程序标识和少量保留英文，不以“含中文行数”计入上面的替换统计。

## 当前限制与测试范围

- **尚未完成游戏内验收。** 不能将离线校验等同于已通关、显示完全正确或手柄完全兼容。
- 本版覆盖剧情与菜单；日记、海报等图片内文字、部分概念画说明和硬编码文字仍保留原样。
- 中文通过原生 Sprite 字形显示，利用细小词间距兼容原版自动换行；特殊气泡、动画、小游戏和字体布局需要进一步实测。
- 未声明蓝牙、其他未知手柄或所有输入转换软件兼容。后备映射会应用于“未知控制器”，其他设备可能需要不同布局。
- Xbox 更新或“验证和修复”可能覆盖补丁；不兼容的新构建需要重新适配。

已完成的检查包括：资源重新解析、未改动对象保持、剧情流程标识一致、字形提取、差分重建 SHA-256，以及模拟目录中的输入安装、汉化切换、恢复和错误版本拦截。参见 [测试说明](docs/TESTING.md)与 [metadata](metadata/) 中的原始统计。

## 存档与恢复

安装工具只操作兼容清单列出的游戏资源，不操作存档、系统驱动、游戏 EXE 或 Xbox 平台组件，也不会启动游戏。原始资源备份保存在游戏 `Content/.nitw-xbox-cn-backup`。

请保留该备份以使用恢复功能。安装与模式切换前都需退出游戏；发生错误时请保留完整错误文本，并参照安装说明处理。

## 源码构建

需要自行提供兼容版本的原始游戏、指定提交的翻译工程与中文字体。完整步骤见 [构建说明](docs/BUILD.md)。

```text
src/                    资源适配与差分构建代码
installer/              CMD 入口和 PowerShell 安装器模板
scripts/package_release.py
                        从差分数据生成可安装的 Release ZIP
metadata/               兼容哈希、来源和离线验证记录
licenses/               翻译与字体许可证原文
tests/                  差分重建与剧情流程保护测试
docs/                   安装、构建、测试和发布说明
```

仓库不提交游戏原件、备份、存档或本机构建目录；安装包通过 Release 附件分发。
